Windows Server & Active Directory Homelab
A practical IT infrastructure homelab built using Microsoft Hyper-V, Windows Server, Windows 11 and PowerShell.
Project Overview
This project involves designing, deploying, configuring and managing a virtual IT infrastructure environment.
The purpose is to gain practical experience in Windows Server administration, virtualization, networking, Active Directory, Group Policy and PowerShell automation.
This homelab is being developed as a hands-on learning project and professional IT portfolio.
Project Objectives
Deploy and manage virtual machines using Hyper-V.
Install and configure Windows Server.
Configure Active Directory Domain Services (AD DS).
Create and manage domain users and groups.
Configure DNS and DHCP services.
Join Windows 11 clients to an Active Directory domain.
Manage users and computers using Group Policy.
Perform network configuration and troubleshooting.
Automate administrative tasks using PowerShell.

Project Architecture
The planned environment consists of:
SERVER01: Windows Server machine that will host Active Directory Domain Services, DNS and DHCP.
CLIENT01: Windows 11 workstation that will eventually join the domain.
Hyper-V: Virtualization platform hosting both virtual machines.
Virtual Network: Internal lab network for communication between the virtual machines.
